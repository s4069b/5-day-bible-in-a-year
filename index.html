Import into Apple Calendar (Mac, iPhone or iPad)

For a separate calendar, create the calendar first, then import the file into it. This makes it easy to show, hide or remove the reading plan.

On a Mac

  1. Open Apple Calendar.
  2. Choose File → New Calendar. Select iCloud if you want it to sync to your Apple devices, then name it (for example, “Bible Reading 2028 ESV”).
  3. Choose File → Import, select the downloaded .ics file, then choose the new calendar as the destination.

Depending on your macOS version, you can also drag the .ics file into Calendar and select the destination calendar.

On iPhone or iPad

  1. First create a new calendar: open Calendar, tap Calendars → Add Calendar → Add Calendar, name it, and save.
  2. Download the .ics file on your device, or send it to yourself and open the attachment in Files or Mail.
  3. Tap the file and follow the calendar import prompts. If your iOS version doesn't offer a destination calendar, import it on a Mac into the iCloud calendar you created.

Menu wording varies between iOS/iPadOS versions. Importing into an iCloud calendar makes it available on devices using the same Apple Account.

Import into a new Google Calendar

Create the destination first.
Google Calendar imports events into a calendar you select; it doesn't automatically create a separate calendar from the .ics file.

  1. Open Google Calendar in a computer browser.
  2. Beside Other calendars, click + and choose Create new calendar. Name it (for example, “Bible Reading 2028 ESV”) and click Create calendar.
  3. Open Settings (gear icon) → Import & export.
  4. Under Import, select the downloaded .ics file and choose the new calendar as the destination.
  5. Click Import. Check the calendar list to make sure the events appear in the new calendar.

Google's .ics import is done on a computer, not in the mobile app. Imported events do not automatically sync with the source file.

Import into a new Outlook Calendar

Make a blank calendar first.
Outlook's web import flow lets you choose a destination calendar.

  1. Open Outlook Calendar.
  2. Select Add calendar → Create blank calendar. Name it and save.
  3. Select Add calendar → Upload from file.
  4. Browse to the downloaded .ics file, then select the new calendar in the destination dropdown.
  5. Click Import.

In classic Outlook for Windows, the import wizard may offer Open as New. Menu names differ between classic Outlook, new Outlook and Outlook on the web.
